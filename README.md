# 🐼 Pandas Practice and Exercises

Welcome to my **Pandas Practice and Exercises** repository! This repository contains my hands-on practice with Python Pandas, using Jupyter Notebook (`.ipynb`) files to learn data manipulation, cleaning, analysis, and combining datasets.

The purpose of this repository is to strengthen my Pandas skills and build a foundation for **Data Analysis, Data Science, and Machine Learning**.

## 📌 Topics Covered

This repository covers the following Pandas concepts:

- **Pandas Series** — Creating Series from lists and dictionaries.
- **DataFrames** — Creating and working with tabular data.
- **Data Selection and Filtering** — Selecting rows and columns and applying conditions.
- **Data Operations** — Performing common operations on DataFrames.
- **Missing Data Handling** — Using `isnull()`, `isna()`, `fillna()`, and `dropna()`.
- **GroupBy and Aggregation** — Grouping data and calculating statistics such as mean, sum, and count.
- **Pivot Tables** — Summarizing data with `pivot_table()`.
- **Apply Functions** — Applying custom functions and using `lambda`.
- **Merging DataFrames** — Combining datasets using `merge()`.
- **Joining DataFrames** — Combining data using `join()`.
- **Concatenation** — Combining DataFrames with `concat()`.

1. Clone or download this repository.
2. Open the project folder in VS Code or your terminal.
3. Make sure Python and the required libraries are installed.
4. Open any `.ipynb` notebook.
5. Run the cells to explore and practice the Pandas concepts.

You can also launch Jupyter Notebook from the terminal:

```bash

```
